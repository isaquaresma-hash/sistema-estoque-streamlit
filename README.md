# 📦 Sistema de Gestão de Estoque e Compras

Sistema completo desenvolvido em **Python** usando **Streamlit**, **SQLite** e **ReportLab**.

## 🚀 Funcionalidades
- 🔒 **Controle de Acesso & Login**: Autenticação com senhas criptografadas e perfis `admin` e `operador`.
- 📦 **Gestão de Produtos**: Cadastro e atualização de preços de custo e nomes.
- 🔄 **Movimentações de Estoque**: Lançamento de compras (entradas) e baixas/vendas (saídas).
- 📊 **Dashboard Comparativo**: Análise comparativa de preços e quantidades movimentadas mês a mês.
- 📄 **Relatório em PDF**: Geração e download de relatórios em formato PDF na própria interface.

## 🔑 Usuário Padrão para Login Inicial
- **Usuário:** `admin`
- **Senha:** `admin123`

## 🛠️ Tecnologias Utilizadas
- **Python** (Linguagem principal)
- **Streamlit** (Interface gráfica web)
- **SQLite** (Banco de dados)
- **ReportLab** (Geração dos relatórios em PDF)
- **Pandas** (Tratamento de dados e comparações)
